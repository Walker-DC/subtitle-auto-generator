# 자막 (영상 -> 자막 -> 검수)

인자: 영상 파일 경로 또는 http 링크 (선택: `--model medium`, 대본 경로). 인자가 없으면 `입력/` 폴더 전체.

## 1. 자막 생성
`python3 make_subs.py <인자> --device cpu` 실행 (작업 폴더: 자막만들기).
- 대본이 `대본/영상이름.txt`에 있으면 자동 사용. 없으면 영상 음성만으로 진행(정상).
- 사용자가 정확도를 원하면 `--model medium`. 기본 small.
- 시간이 오래 걸리면 백그라운드로 실행하고 끝나면 확인.

## 2. 검수 (자동 적용 전 반드시 이 순서로)
`출력/영상이름.srt`와 `출력/영상이름.검토.txt`(낮은 신뢰도·대본 불일치), `용어목록.txt`를 읽고 다음을 점검한다.
1. 어색하거나 문법이 틀린 문장 (예: "못 고리고" -> "못 그리고")
2. 같은 이름·용어가 구간마다 다르게 적힌 곳 (표기 통일)
3. `.검토.txt`의 항목 전부
4. 용어목록 [용어]/[교정] 위반

## 2.5 외부 검색으로 고유명사·알려진 단어 확인 -> `사전전문가` 에이전트에 위임
후보 목록(시간, 문구, 앞뒤 문맥)과 영상 제목을 Agent(subagent_type: 사전전문가)에 넘기고 표를 받는다. 아래 규칙은 그 에이전트와 같다.
영상 제목(파일명)과 자막 전체의 맥락을 보고 후보를 뽑는다: 인물/게임/작품/지명/브랜드/신조어, 신뢰도 낮거나 구간마다 표기가 다른 단어. 인식이 엉뚱한 단어로 나온 경우는 주제 문맥으로 원래 단어를 추정해 후보로 삼는다.
- WebSearch로 정식 표기를 확인한다. 검색어에 영상 주제를 함께 넣어 동명이인/동명작을 구분한다. (ToolSearch로 WebSearch를 먼저 로드)
- **서로 다른 출처 2곳 이상이 같은 표기를 가리킬 때만** 자동 반영한다. 출처가 엇갈리거나 못 찾으면 고치지 말고 질문 목록에 올린다.
- 표기가 여럿이면(공식 번역명 vs 통용 표기) 사용자에게 고르게 한다. 확정된 값은 `용어목록.txt`에 저장.
- 외부로 보내는 건 단어(텍스트)뿐이다. 영상/음성은 보내지 않는다.

## 2.6 애매한 문장 -> `자막조정` 에이전트에 위임
사전전문가가 확정한 용어와 애매한 문장 목록(어색한 말투, 표기·말투 불일치, 의미가 불분명한 곳)을 Agent(subagent_type: 자막조정)에 넘기고 조정안 표를 받는다. 두 에이전트는 파일을 수정하지 않는다. **적용은 이 스킬이 한다.** 확신 '높음'과 '확정'만 적용, 나머지는 사용자에게 묻는다. 서로 독립이면 두 에이전트를 병렬로 호출해도 된다(단, 자막조정은 확정 용어가 필요하면 사전전문가 결과 후).

## 3. 교정
- 문맥상 확실한 오타/조사/띄어쓰기는 `.srt`를 직접 고친다. **타임코드와 문장 수(번호)는 바꾸지 않는다.**
- 고유명사나 의미가 불확실한 곳은 추측해서 고치지 말고, 사용자에게 표로 묻는다. (근거 없이 고유명사를 만들어내지 말 것)
- 고친 뒤 `python3 srt2vtt.py 출력/영상이름.srt`로 .vtt 동기화.
- 사용자가 확정해 준 이름/용어는 `용어목록.txt`의 [용어]에, 반복되는 오인식은 [교정]에 추가한다.

## 4. 보고 (한국어)
- 결과 파일 경로
- 고친 곳: `전 -> 후` 목록 (외부 검색으로 고친 건 근거 출처 한 줄씩)
- 확인이 필요한 곳(불확실): 시간, 현재 문구, 후보
- 사용한 모델과 대본 사용 여부
